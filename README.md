กำหนดให้ x คือ กำเเพง เดินชนไม่ได้  <br>
กำหนดให้ s คือ ตำเเหน่งผู้เล่น <br>
กำหนดให้ _ คือ ทางทที่เดินได้ <br>
กำหนดให้ o คือ เส้นชัย <br>

```
 [x][x][x][x][x][x][x][x]\n[x][x][x][_][_][x][x][x]\n[s][_][_][_][x][x][o][x]\n[x][x][x][_][x][x][_][x]\n[x][x][x][_][_][_][_][x]\n[x][x][x][x][x][x][x][x]\n
```
